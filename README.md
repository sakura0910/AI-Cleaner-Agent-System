# AI Cleaner Agent System

## 项目概述
AI Cleaner Agent System 是一个基于多 Agent 架构的 AI 智能磁盘管理系统，主要面向 Windows 环境下的 C 盘清理与治理。

该系统通过多 Agent 协作与长链推理机制，模拟真实的大模型调用场景，并重点体现高 Token 消耗下的智能决策能力与安全执行流程。

---

## 核心问题
传统磁盘清理工具无法有效区分以下几类文件：
- 系统关键文件
- AI 开发过程中产生的缓存（如模型权重、IDE 索引）
- 临时文件或冗余数据

这可能导致：
- 误删重要文件
- 清理策略不智能
- 开发环境受影响

---

## 系统架构

### 1. Scanner Agent（扫描代理）
- 遍历磁盘文件
- 收集文件路径、大小、类型等基础信息
- 构建磁盘数据画像

### 2. Analyzer Agent（分析代理 / 高 Token 消耗核心）
- 模拟调用大语言模型（如 MiMo / GPT 类模型）
- 对文件进行语义级分析（用途、来源、安全性）
- 基于上下文进行推理判断
- 输出分类结果与 Token 消耗日志

### 3. Executor Agent（执行代理）
- 基于 Analyzer 的分析结果进行决策
- 支持多步推理（如依赖关系判断）
- 在受控环境中执行清理策略

---

## 多 Agent 工作流程
1. Scanner Agent 扫描磁盘并采样文件
2. Analyzer Agent 对文件进行语义分析与推理
3. Executor Agent 根据分析结果制定执行策略
4. 系统记录推理过程与 Token 消耗

---

## Token 消耗模拟
- 每日约处理 5000 次分析请求（模拟场景）
- 单次推理约消耗 1200–2800 Tokens
- 预计每日 Token 消耗约 1000 万

该设计用于模拟大规模 LLM 在系统工具中的实际使用情况。

---

## 功能特点
- 多 Agent 协同架构
- 长链推理能力
- AI 驱动的智能决策
- Token 使用量统计与展示
- 安全执行机制（默认不进行真实删除）


## 安全机制
系统默认运行在 **SAFE MODE（安全模式）**：
- 不执行真实文件删除
- 所有操作仅做模拟与日志输出
- 避免对操作系统造成影响
